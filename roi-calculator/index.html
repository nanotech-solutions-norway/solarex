Calculation method

Environmental data first. Manual assumptions second.

The ROI calculator is configured as a browser-only static tool. It stores no customer data and uses public environmental-data endpoints when available.

01

PVGIS annual PV output

Preferred baseline where accessible from the browser because it estimates annual PV energy output directly from coordinates, peak power, tilt, azimuth and system-loss assumptions.

02

Open-Meteo fallback

Fallback using hourly global tilted irradiance and sunshine duration for the most recent full calendar year.

03

Manual full-sun hours

Controlled fallback for validated customer/site assumptions or temporary external API unavailability.

Pathway logic

Quartz and Titan are different technical mechanisms.

SolarEX Quartz SiO₂

Passive UV-independent hydrophobic/oleophobic easy-clean PV glass route for relevant dust, pollen, salt, sand, grime and bird-lime contexts.

Passive route

SolarEX Titan TiO₂

Active UV-dependent TiO₂ photocatalytic and hydrophilic/superhydrophilic route where organic or atmospheric contamination supports that mechanism.

Active route
