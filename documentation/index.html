Documentation FAQ

Common documentation questions.

Why are direct downloads not active yet?

Final file paths, approved document versions and backend tracking must be confirmed before direct download activation.

Can Quartz and Titan documents be used interchangeably?

No. Quartz documents support passive SiO₂ review. Titan documents support active UV-dependent TiO₂ review.

Where should customers request files?

Until final download endpoints are active, customers should use Technical Review or Contact to request the correct document set.

What files require extra approval?

SDS, TDS, confidential partner files, private backend configuration and unapproved commercial documents require explicit approval before publication.
